IP 信息

多源 IP 智能与网络连接诊断工具。

多源 IP 交叉验证

大多数 IP 查询工具只查询单一服务器。IP 信息会通过 Cloudflare 边缘节点、公共 IP 服务商（ipify、ipwho.is、IP.SB、ip.guide、SeeIP、icanhazip、IPIP.net）以及浏览器 WebRTC STUN 候选地址，交叉验证客户端 IP 与网络数据，以诊断 VPN/代理绕过、发现各地理位置数据库之间的坐标差异，并测量往返延迟。

快捷 CLI 终端访问

直接在终端中使用 curl 或 wget 查询你的 IP：

# Plain public IP
curl -sL https://ip.666200.xyz

# Formatted JSON diagnostic info
curl -sL https://ip.666200.xyz/api/v1/info?format=json

# YAML metadata
curl -sL https://ip.666200.xyz/api/v1/info?format=yaml

全面诊断

  • 零延迟边缘地理位置：直接从 TLS 连接头中提取城市、地区、坐标与 ASN。
  • WebRTC STUN 泄漏检测：检查浏览器 ICE 候选地址，检测跨 VPN 的未加密 IP 泄漏。
  • DNS 泄漏检测：解析唯一随机子域名查询，揭示上游递归 DNS 解析器。
  • 注重隐私：服务器端零 IP 日志，历史记录 100% 保存在设备本地。
